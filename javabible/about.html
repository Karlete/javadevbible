Who writes this, and why it exists

← Back to Index

I'm Carlos. I've been writing software professionally since 2018, and it has been Java the whole way.

JavaDev Bible is my own corner of that work. I wanted one place that gathers as much as I could: the fundamentals, the frameworks, the tooling, and the parts of the ecosystem you only meet once a year.

Part of the reason is memory. Things fade. Some you learned once and never used in production. Some you used every day until a project moved on and they stopped ringing a bell. Some are simply out of date, and you only notice when you are halfway through explaining them to someone. This is where I go to get them back.

The other reason is a bit stubborn. Today an AI writes much of the code we used to type by hand, XD. I still think it is worth knowing why that code works and how. When the generated code breaks, knowing what's underneath is the only thing that helps.

Take it with you

The whole site is plain HTML, CSS and JavaScript. It needs no account and no server, and once you have it, no internet. Download the zip, unzip it, open it, and that's it. The pages read straight from the files; the search box fetches its index, so for search start a local server inside the javabible folder with python -m http.server and open localhost:8000.

It also ships with an MCP server, so you can plug it into your own AI assistant and have your own Java bible answering from it. How to run it is in mcp/README.md inside the same zip.

Every code example uses the same online shop; its packages, entities and order lifecycle are described in the project behind the examples.

The source is on GitHub: github.com/karlete/javadevbible.
